# Stitch Design Archive Index

This directory stores design explorations, generated references, and historical assets.

## Canonical Rule

- Root `DESIGN.md` is the official active design source.
- Files in this directory are reference material unless they are promoted into the root design brief.

## Key References

- `project_prd_talent_rdc_express.md`: historical product and brand brief used during early design exploration.
- `vibrant_enterprise/`: source exploration that informed the current official visual direction.
- `professional_trust_interface/`: alternate, more conservative design direction kept for comparison.

## Archive Structure

- Mobile and desktop exploration folders store screenshots or generated mockups for specific screens.
- Logo-related folders store intermediate concept outputs and should not be treated as approved assets by default.

## Working Rule For Agents

- Do not scan every folder here for routine implementation work.
- Use `data/context.md`, `DESIGN.md`, and `AGENTS.md` first.
- Consult this archive only when a task explicitly requires historical design comparison.
